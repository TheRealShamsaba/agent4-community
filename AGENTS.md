# Working on Agent4 Community

This is the public, empty starting point for independent teams. Preserve that boundary.

- Never copy another repository's Git history, environment files, ignored artifacts, runtime data, private audits, deployment infra, screenshots, company logos, contacts or account identifiers.
- Use fictional fixtures and reserved example domains/phone numbers. Check comments, templates, asset metadata, generated bundles and commit authors as well as runtime defaults.
- Keep core authentication required. Preserve first-owner claim protection, session CSRF, exact Origin validation, invite revocation, owner/member permissions and actor-scoped personal data.
- Module choices organize the UI; they do not grant or deny access. Do not delete data when a module is hidden.
- Keep company-specific configuration and truly independent private services outside the public tree. Port general improvements deliberately; never blanket-sync a private checkout.
- Run npm run verify and the dependency audits for behavioral changes. Run the source and secret checks before pushing.
- Commit only explicit reviewed paths. Local data and the private audit may exist in this workspace and must stay ignored.
